# Scraping_SHEGLAM

A Data Science project that leverages Selenium to scrape product data from the [SHEGLAM](https://www.sheglam.com/) website. The project focuses on collecting detailed information about products, including:

- Product Names  
- Prices  
- Categories  
- Ratings

---

## Project Overview

This project demonstrates the end-to-end workflow of a real-world data science pipeline:

1. Web Scraping  
   Using `Selenium` to dynamically extract product details from the SHEGLAM website.

2. Data Preprocessing  
   Cleaning and organizing the raw scraped data using `pandas`.

3. Data Analysis & Visualization  
   Exploring trends, price ranges, category distributions, and rating summaries using `matplotlib` and `seaborn`.

4. Interactive Dashboard  
   Displaying insights via an interactive web app built with `Streamlit`.

## Run locally

The repository does **not** include a product-data CSV. The scraper notebook creates
`sheglam_products.csv`; the dashboard needs that file and will show a setup message
until it is present. No sample or synthetic product data is supplied.

1. Use Python 3.10 or newer and create/activate a virtual environment.
2. Install the pinned dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Open `SHEGLAM_WEB_SCRAPING.ipynb` in Jupyter or Colab and run the scraping
   section. Selenium 4 uses Selenium Manager to locate/download a compatible
   browser driver; have Chrome or Chromium installed and available. The site may
   change its markup or restrict automated access, so scraping is not guaranteed.
   The notebook writes `sheglam_products.csv` in its current working directory.
4. Place that CSV next to `app.py` (the project root), then run:

   ```bash
   streamlit run app.py
   ```

The dashboard expects these columns: `Category`, `Name`, `Price`, `Stars`,
`Subcategory`, and `Best Seller`. Keep the CSV local; it is intentionally not
committed because it is generated by the scraper and can contain changing product
data. The notebook's separate MongoDB example expects a MongoDB service on the
local machine.
